# Seletor de Personagens

Esse é um projeto que fiz para praticar HTML, CSS e JavaScript. A página mostra alguns personagens e permite escolher qual deles queremos ver.

## O que dá para fazer

- Ver o personagem selecionado, com uma imagem e uma descrição.
- Clicar nos botões redondos para trocar de personagem.
- Usar a página em telas grandes e pequenas, com imagens diferentes para cada tamanho.

Os personagens que aparecem são Cyberstorm, Codepixie, Hexblade, Neonpulse e Codebreaker. Apesar do nome do projeto, as histórias são de personagens com tema de tecnologia.

## Tecnologias usadas

- HTML para montar a página.
- CSS para os estilos e o layout responsivo.
- JavaScript para fazer a troca dos personagens quando clicamos nos botões.

## Como abrir o projeto

Não precisa instalar nada. Baixe ou clone este repositório e abra o arquivo `index.html` no navegador.

## Pastas e arquivos

```text
.
├── index.html
└── src
    ├── css
    │   ├── reset.css
    │   ├── responsivo.css
    │   └── style.css
    ├── img
    │   ├── imagens dos personagens
    │   └── ícones dos botões
    └── js
        └── index.js
```

O arquivo `index.html` tem o conteúdo da página. Os arquivos dentro de `src/css` cuidam da aparência, `src/img` guarda as imagens e `src/js/index.js` controla a seleção dos personagens.
